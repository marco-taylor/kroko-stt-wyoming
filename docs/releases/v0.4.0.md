# v0.4.0 — Improved German Community-128 decoding

German Community-128 now uses `modified_beam_search` with 4 active paths and
zero blank penalty. Classic and Community-64 retain `greedy_search`; custom
models and other languages retain their existing decoder. There is no Beam-8
option or additional decoder environment setting.

True online streaming, audio handling, chunk/context configuration, endpointing,
Wyoming behavior and model weights are unchanged. Existing complete models are
reused: no model migration or new download is required when updating.

In a controlled CPU-only, single-thread benchmark on 862 distinct FLEURS-DE
recordings, Community-128 WER improved from **8.102% to 7.188%**: **0.914
percentage points / 11.28% relative**. The paired-bootstrap 95% interval for
improvement was **[0.659, 1.194] percentage points**. CPU time increased by
approximately 5%. These are benchmark results, not a promise for every speaker,
recording environment or Home Assistant command.

Existing Classic installations remain supported without automatic model
replacement. Keep the existing persistent model mount and model selection.
Community-128 remains the default for new installations.
